# Revision-stage policy comparison

The completed post hoc comparison reuses original 25% masks in both collections. All 2,400 policy rows, 120 condition-endpoint summaries and 100 paired summaries are supplied. No experiment was rerun for release. See POLICY_SPEC.md and Supplementary S14 for the fixed design and definitions.

The code requires private cached similarities and the original project loader revision_mask_intensity. It is inspectable code, not a standalone public raw-to-score route. Python 3.12.14 and NumPy 2.3.5 were used for the completed run. The original 5,000-arm public scalar package verifies title-substitution/SPECTER2 endpoints, not these removal vectors. The 7,200-comparison independent bridge covers fallback arms only. Verification.json records original checks and exact code/specification/CSV hashes.
