# Post-confirmation OpenAlex field-availability calibration

Written 6 October 2026 before bulk retrieval or calibration scoring. This is a new, post hoc external-validity audit; none of the original frozen results or inference families changes.

## Question and provider choice
Does a dated public scholarly metadata API expose abstracts for the same 7,190 historical records used in the two frozen experiments, and is field unavailability associated descriptively with their fixed source/year cells? OpenAlex is selected for its public exact-DOI OR retrieval, explicit nullable abstract field, reproducible identifiers and a verified free request allowance. The 12-record metadata-only feasibility probe returned HTTP 200 and all DOIs; no novelty outcomes were used in provider selection. No account, payment or additional corpus is involved. The actual response allowance was 1,000 list requests/day; about 72 batched requests suffice.

## Fixed frame and acquisition
Use all historical 2018–2020 records from the unchanged ACL confirmation and biomedical replication, without sampling, outcome filtering or new exclusions. Exact normalized DOI only; preserve original source/year. Sort DOI and retrieve in fixed batches of 100, selecting ID, DOI, publication year and abstract_inverted_index. Cache original bytes, UTC time, HTTP status, headers, request URL and SHA256 atomically. One sequential request at least one second apart, finite retries for transient errors only. Validate response count, duplicates and unexpected DOIs. A batch is complete only after checksum and request identity checks. Stop for access restriction/budget exhaustion; never rotate identities, bypass controls or pay.

## States and estimands
For exact uniquely matched records, distinguish (i) a structurally valid nonempty inverted index, (ii) explicit null abstract index, (iii) empty/malformed index, (iv) ambiguous duplicate DOI. Unmatched/indexing failure and HTTP errors are separate unknown states. A null API field means the provider does not expose an abstract in this snapshot, not that the publication lacks an abstract, that rights explain absence, or that it was unavailable when published. Structurally valid does not establish semantically correct text. Do not reconstruct or substitute provider text, and do not treat unavailable entire records as missing abstracts. Report all-state counts, matched-DOI denominator and full-frame denominator by collection/source/year. Coverage associations are finite-frame descriptive; no paper-population sampling inference.

## Gate for deterministic endpoint calculation
Apply the observed null-index pattern to the existing authentic-title fallback only if every historical DOI in that collection maps uniquely, every API response succeeds, and every matched abstract state is valid-present or explicit-null. Otherwise report coverage only and refuse an unambiguous full-frame observed mask. Do not classify unresolved records as present or absent, or search for another provider based on outcomes. If the gate passes, use the unchanged cached SPECTER full/title vectors and unchanged full focal vectors to recompute the existing G,T,Q once, with lost-paper count and fixed cutoff qualifications. This is one observed dated mask, with no Monte Carlo interval and no inclusion in the original 45/18 families. A zero-null mask is valid but uninformative about instability. Values outside 10/25/50% do not validate those scenarios. No simulated rate is retroactively called empirical.

## Reporting and preservation
Save all new scripts, manifests, field-state CSV, coverage tables and any deterministic scores only in scientometrics_revision/analyses/calibration. Preserve originals, pilot, seeds and freezes. Do not redistribute retrieved abstract content without a separate rights decision; public-ready outputs may contain identifiers, counts, hashes and non-text summaries. Capture code/protocol hashes before acquisition. Describe any failed full-frame calibration explicitly and use its limitation in manuscript and revision report.
