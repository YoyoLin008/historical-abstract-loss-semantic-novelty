# Data dictionary

The complete per-file/per-column dictionary is `csv_dictionary.csv`; it covers every original numerical CSV, identifier projection and provenance filename map. `manifests/csv_schemas.json` binds exact fields, row counts, semantic types and observed missing counts, and `scripts/validate_release_data.py` checks each. Record and assignment IDs are strings, never coerced to numeric identifiers. All data are UTF-8; CSV blanks remain explicit original missing values. Date stamps are UTC. Decimal fractions are not percentages; display scripts multiply T/Q by100. Counts of papers in a single mask are integers; means of those counts are expected paper counts and can be fractional.

ACL:n1557,k156;biomedical:n1471,k148. G uses its encoder-specific baseline population SD; T uses fixed k; Q uses n−1 and average ties. Outside-band conditional loss denominators are140/132. Source-specific per_k uses total k, not source-specific selection counts. Signed-margin bins are left-inclusive/right-exclusive, and exact zero is in[0,.01). Rank-band and positive-margin counts are distinct, overlapping threshold-based summaries. Verified actual baseline membership at δ=.10: ACL margin set (132 papers) is a subset of outside-band selections (140); biomedical outside-band selections (132) are a subset of margin set (133). Their corresponding loss counts therefore admit the appropriate nested-subset subtraction in these exact cohorts. Inside+outside forms the full rank-band partition; the positive-margin total is not an additional disjoint component. Fixed thresholds do not imply human cost or general validity.

`mean`, `sd_over_masks`, `p05` and `p95` describe mask outcomes. `mcse` and Student intervals describe the mean over the fixed synthetic-mask distribution. Original family sizes45(ACL)/18(biomedical) are separate; SPECTER2's12-mean family and 200000-resample sensitivity are post hoc. No confidence statement covers all scientific fields. Descriptive Wilson intervals describe joint mask frequency only. Marginal endpoints with no inferential interval remain blank; empty-bin rates remain undefined. `topic` is preserved original filename/condition language for a transparent lexical proxy, not human subject annotation.

JSON dictionaries: each `baseline_cutoff.json` stores band rule; n,k; raw baseline source contrast and contrast/SD; baseline population SD; selected in/outside band counts; kth/next/midpoint raw scores and raw/standardized gap; low/high rank-band indices; rank-band size; tied-block selected/size; far-loss and rank-normalization denominators. `cohort_construction_metadata.json` stores original metadata manifest hashes, date definition and distinct duplicate-exclusion scope. `readout.json` stores separate SPECTER2 critical value, df199, family12, scope/status and the same primary/paired endpoint rows as CSV. `sensitivity_summary.json` stores fixedB,63 mean/13 joint comparisons, concordance/Monte Carlo sensitivity and actual elapsed/RSS; timing is execution provenance, not scientific precision. `pilot/diagnostic.json` records all three prespecified model feature/training/holdout definitions, coefficients,60 heldout target/prediction arrays and their MAE/RMSE; test errors can be recreated without a model refit. Original configs/freezes/seeds retain their original keys/hashes/assignment definitions; their absent input paths are requirements, not downloadable data. `scientific_provenance.json` separates frozen experimental commits and historical generation metadata from verified software release commit/tag/DOI metadata.

`docs/results_map.csv` is a routing table: display identifies article/supplement location, input is a release-relative path, row_selector gives the exact relevant subset, reproduction_command names the shortest command, scope states what that command can recreate. `manifests/original_to_release.csv` records original/export path, SHA256, file role, declared transformation and function-AST equivalence when applicable. These routing schemas are documented here because they contain filenames rather than scientific measurements.

`original_biomedical/cohort_profile.json` is a non-text projection of original cohort construction: publisher_frame_count (4,896 total candidate DOIs); history_count/focal_count (3,391/1,471); profile gives source/year publisher_candidates, DOI matching/date/type/identifier eligibility, joint text availability and eligible_final counts. Exclusion categories can overlap (30 type and10 retraction/concern;34distinct records); no simple disjoint addition is claimed. Original retrieval date, rules/records hashes and date definition remain explicit. The dictionary CSV fields are file (release-relative input), column (literal CSV header), type (semantic scalar type), meaning (scientific definition), units, denominator_or_inference (study,k,n/family), mechanism_rate_replicate (row scope), and missingness (original blank count/reason). No unspecified column interpretation is required.

Cutoff verification adds two CSVs with all column definitions in the per-file dictionary. The three `*_lost_ids.jsonl` contain one saved scored arm per line: study/encoder/assignment_id/role/mechanism/rate metadata; original computed G,T,Q; selected_lost_count; inside_count/outside_count and their original k-normalized fractions; conditional outside loss fraction; four strict positive-margin `far_loss_count_delta` values; actual `lost_ids`, `outside_ids`, and `far_ids` keyed by .01/.025/.05/.1. Each list holds unique original paper strings. Empty lists are known empty sets, never missing data. There are 3,000 ACL, 1,200 biomedical and 800 SPECTER2 saved scored-arm rows. SPECTER2 reuses the original 25% assignments; these 5,000 rows are not all independent new mask draws. The JSONLs are lean numeric/ID projections, not byte-copies of full scientific score files. Full masked-score vectors, source text and embeddings are absent. `baseline_set_summary.json` contains only sanitized numerical set counts/relations and comparison totals from original verification; private absolute paths and other private audit fields are omitted.

`manifests/jsonl_schemas.json` explicitly declares required field order/types and exact 3,000/1,200/800 record counts for the lost-ID proofs. The release validator checks every field for nulls, finite numbers, nonnegative native integer counts, nonempty string IDs and uniqueness of all ID lists; it never supplies missing empirical values.

The current administrative `manifests/license_scope.csv` has 146 reviewed file rows and eight columns: path, license, authorization, origin, origin_sha256, rights_scope, copyright_holder and copyright_year. Origins and source hashes identify antecedents, not recursive current hashes. Historical v1.0.0 scope is retained separately under manifests/history/. New mapped grants were explicitly approved on 8 October 2026. This table has no mask assignment, denominator or uncertainty family; docs/license_scope_policy.md states the exact limits.

## Version 1.1.0 revision-stage additions

The core fields are documented in revision_core_dictionary.csv and claim_provenance.csv. Mechanism fields are documented in revision_mechanism_dictionary.md. source_shifts.csv separates signed D, absolute G and drift M; all use original baseline population SD. conditional_loss_by_margin.csv uses fixed baseline-selected bin denominators; empty bins are undefined. cutoff_capacity.csv is set accounting, not a new inferential test. Encoder overlap compares each complete-history top-k. The source/lexical intensity and neighbor summaries retain assignment SD/percentiles/defined counts with 200 masks per condition; overlapping source/all rows are not independent observations. Loss in intensity tables denotes masking percentage; selected loss in neighbor tables uses the baseline-selected count within source. The source-release mappings identify exact bytes and transformations, not inferential variables.
