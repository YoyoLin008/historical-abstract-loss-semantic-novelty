# Historical abstract loss and semantic novelty: reproducibility materials

Reproducibility materials, **version 1.0.0**, prepared for journal submission. This does not imply journal submission or acceptance. The frozen **v1.0.0** release is archived at [Zenodo, DOI 10.5281/zenodo.23222368](https://doi.org/10.5281/zenodo.23222368). Cite this version DOI for the reported computation. Its release commit is `82bd064fae8f4aff9a2f0b56bb9ec850bd649e89`; later documentation on the main branch does not change the archived release. Author: Yunya Lin. This is a sanitized export of the actual study, with original source/configs/seeds, bibliographic identifier projections and original non-text numerical outputs. The original ACL/biomedical freezes and all post-confirmation labels are retained. Substantial AI assistance is disclosed; these materials do not replace human scientific responsibility.

Run the reporting route in `docs/reproduction.md`. Start with `python scripts/validate_release_data.py`, `python scripts/rebuild_tables.py`, then `python scripts/rebuild_figures.py --project . --out outputs/figures` and the cutoff verification command below. No source project path, raw-text cache, embedding array, model weights or network access is required for those commands. Original fixture tests also run locally. `docs/results_map.csv` maps every main/supplement display to its real inputs. `docs/data_dictionary.md` documents all numerical/identifier CSVs and uncertainty scope.

The release supports reporting-level reconstruction; public cached-score/full raw-to-encoder reproduction is incomplete because original text/arrays/caches are omitted. Prior exact cached-vector reproduction is distinct from this package's executed scope. See the reproduction-level documentation before claiming a full rerun.

Data layout: `data/derived/original_acl`, `original_biomedical`, `post_confirmation/{openalex,bootstrap,specter2}`, and `pilot`. `data/identifiers` contains no titles/abstracts. Original main scientific modules remain in `src`, `analysis` and `replication`; path-adapted post-confirmation sources are explicitly marked. `manifests/original_to_release.csv` provides old/new filename identities and original/export SHA-256 bindings. Any new sanitized export history is separate from the historical experiment repository.

Source contrast, rank and selection response are distinct measurement uses. SPECTER2's biomedical baseline contrast changes sign and becomes near zero; this is a representation-dependence limitation, not construct validation. OpenAlex calibration and the pilot diagnostic remain unsuccessful. Results are conditional on fixed cohorts/pipeline/synthetic masks; intervals quantify variation over mask assignments, not uncertainty across scientific fields. No claim of exhaustive novelty clearance or acceptance probability is made.

The author has approved the scoped licenses: MIT for the 37 mapped original Python files; CC BY 4.0 for the 79 mapped own non-text/data/configuration/provenance/documentation files and the explicitly named new release-policy documentation. `LICENSE`, `manifests/license_scope.csv` and `docs/license_scope_policy.md` define the per-file split. No blanket rights are assigned to source abstracts, weights, libraries or arrays. `docs/data_rights.md` and `THIRD_PARTY_NOTICES.md` explain exclusions. Checksums validate integrity, not empirical validity. Preserve original full-precision results.

Cutoff diagnostics use distinct, overlapping threshold-based summaries. At δ=.10 the verified ACL margin set (132) is nested within outside-band selections (140); biomedical outside-band selections (132) are nested within its margin set (133). Appropriate subset differences are valid for these fixed sets. The public source fixtures include a deliberately nonnested synthetic counterexample, which tests endpoint code generally and does not describe the empirical cohort. No scientific numerical value changed in this corrected explanatory language.

Targeted cutoff proof is also released: `python scripts/verify_cutoff_membership.py --data data/derived/cutoff_verification`. It reconstructs selected sets, tie-expanded rank bands and positive margins from the four original/SPECTER2 scalar baseline score lists, then verifies 16 baseline comparisons and 20,000 saved loss-ID intersections. The 5,000 saved scored arms consist of 4,200 original arms and 800 limited SPECTER2 arms; the latter reuse the original 25% mask assignments and are not new independent draws. The lean public JSONLs selectively retain numeric endpoints and ID memberships from saved scientific outputs; later private movement-field additions are not part of this public projection. Full masked-score vectors remain omitted, so this supports reporting-level membership verification. Baseline scalar scores are original non-text numerical outputs included specifically for inspectable cutoff proof. Their origin hashes and transformation scope are in `manifests/cutoff_inputs.json`.
