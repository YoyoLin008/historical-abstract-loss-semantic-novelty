# Author preprint and supplementary materials

Yunya Lin. *Historical abstract loss and use-dependent robustness of a semantic novelty indicator.* Public-access edition,11 October 2026. This is an author preprint, not peer-reviewed, accepted or published by Scientometrics. No journal submission has been made by this release.

Read manuscript.pdf, ESM_1.pdf and ESM_2.zip. The paper's scientific results are those of the verified8 October manuscript; edits in this edition concern preprint labeling and the newly public scalar-verification access. The separately completed10 October policy-comparison audit is not silently incorporated. Identified literature/editorial improvements remain possible in a later manuscript version; this is not a certification of journal readiness.

The complete scalar reconstruction package is at ../verification/scalar_scores/. It reconstructs5,000 arms/75 family means, with ordered IDs, baseline/masked scores, original masks, pair mappings, expected outputs, code and dependencies. The 10focal-neighbor files, raw text, embeddings, weights, private history and correspondence are excluded.

The public repository's LICENSE and per-file scope apply. References, facts and third-party rights are not relicensed. Availability of the scalar package establishes an executable score-to-endpoint route, not full raw-data acquisition/encoding reproduction. The original public v1.0.0 and v1.1.0 archives are immutable.
