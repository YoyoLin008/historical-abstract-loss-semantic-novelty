# Exact version-specific license scope

`manifests/license_scope.csv` enumerates every v1.1.0 file and its one applicable license. MIT covers only the explicitly named original Python code and tests; CC BY 4.0 covers only named original documentation, configurations, metadata, identifiers and derived non-text numerical materials. These are per-file assignments, not alternative licenses for every file. No arbitrary future file inherits a license merely from its extension.

The historical v1.0.0 inventory remains in `manifests/history/v1.0.0_license_scope.csv`. Exact unchanged historical payloads retain their prior authorization. The author explicitly approved the 146-file v1.1.0 scope before publication on 8 October 2026, including the seven new MIT and 33 new/changed CC BY 4.0 assignments. Status/DOI documentation updates implement the authorized handoff. These grants do not extend to arbitrary future files. Source hashes in the table identify reviewed antecedents, not recursive current checksums. `manifests/export_files.json` hashes every release file except itself; an external approval allowlist binds the full candidate including that manifest.

These grants apply only to rights the author may license. They do not create proprietary rights in facts, extend to omitted or third-party materials, or authorize manuscript publication or journal submission. Standard license text retains its own terms.
